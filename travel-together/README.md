# Travel Together

Travel Together is a seatback social prototype for seat-to-seat invites, synchronized viewing, and visually rich game-session concepts.

![Travel Together screenshot](./travel-together-screenshot.png)

## Rendering instructions

1. Download or clone this repo to a local folder.
2. Open PowerShell in the repo root.
3. Run `python -m http.server 8080`.
4. Open `http://localhost:8080/travel-together/travel-together-prototype.html`.
