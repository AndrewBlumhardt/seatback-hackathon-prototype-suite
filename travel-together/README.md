# Travel Together

Travel Together is a social entertainment concept developed for a Microsoft internal hackathon submission. It explores how seatback systems can connect passengers into lightweight shared experiences rather than isolating each screen.

## Project idea narrative

### The problem it addresses

Current IFE experiences are mostly single-user. Families, friends, or newly connected travelers often cannot easily coordinate playback, chat, or game sessions across seats, which limits social engagement on longer flights.

### Proposed experience

Travel Together introduces a collaborative interaction layer:

1. Invite by seat to form ad hoc groups.
2. Sync media playback across connected seats.
3. Exchange lightweight group chat and status cues.
4. Launch casual shared game sessions (for example Chess, Checkers, Solitaire, and Kart Racing concepts).
5. Expand selected game visuals into a larger in-app focus mode for presentation and group awareness.

The design aims to keep interaction intuitive and cabin-appropriate while still feeling playful and connected.

### Why it matters

For passengers, this adds companionship and shared fun to long-haul travel.  
For airlines, it creates a differentiated social feature set that can increase onboard engagement and perceived value of the seatback platform.

### Hackathon demo scope

This prototype demonstrates the social UX pattern, synchronized controls, and game-session visualization concepts. It intentionally stops short of production-level multiplayer networking, account identity orchestration, or commerce integration.

## Rendering instructions

1. Download or clone this repo to a local folder.
2. Open PowerShell in the repo root.
3. Run `python -m http.server 8080`.
4. Open `http://localhost:8080/travel-together/travel-together-prototype.html`.
