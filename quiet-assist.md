# Quiet Assist

Quiet Assist is a discreet support concept with passenger request flows, crew queue management, seat-map triage, and translation controls.

![Quiet Assist screenshot](./quiet-assist-screenshot.png)

## Rendering instructions

1. Download or clone this repo to a local folder.
2. Open PowerShell in the repo root.
3. Run `python -m http.server 8080`.
4. Open `http://localhost:8080/quiet-assist-prototype.html`.
