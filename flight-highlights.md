# Flight Highlights

Flight Highlights is a route-and-camera concept featuring live camera switching, timeline pin replays, and post-flight summary/share workflows.

![Flight Highlights screenshot](./flight-highlights-screenshot.png)

## Rendering instructions

1. Download or clone this repo to a local folder.
2. Open PowerShell in the repo root.
3. Run `python -m http.server 8080`.
4. Open `http://localhost:8080/flight-highlights-prototype.html`.
