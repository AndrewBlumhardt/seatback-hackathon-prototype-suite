# Travel Together

Travel Together is a social in-cabin concept with shared viewing, seat-based invites, group chat, and visualized game-session demos.

![Travel Together screenshot](./travel-together-screenshot.png)

## Rendering instructions

1. Download or clone this repo to a local folder.
2. Open PowerShell in the repo root.
3. Run `python -m http.server 8080`.
4. Open `http://localhost:8080/travel-together-prototype.html`.
